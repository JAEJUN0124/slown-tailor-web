# SLOWN 공식 스토어 — 브랜드 자사몰 화면 목업 (데모)

SLOWN이 직접 운영하는 공식 온라인 스토어 목업입니다. 레퍼런스 브랜드 공식몰에서 로그인 없이 열리는 화면(홈·목록·상품 상세·검색·매거진·브랜드/서비스 안내·회원·장바구니·주문서·게시판)을 모두 분석해 화면 구조와 수치를 맞췄습니다. 회사 정보·상품·가격·리뷰·매장·입점처·약관·FAQ는 모두 샘플입니다.

- 스택: Next.js 16(App Router, 정적 export) · React 19 · Tailwind CSS v4 · lucide-react
- 배포 위치: `/<repo>/store/`

이 폴더(`official-store/`)에서 실행합니다. 개발 서버는 http://localhost:3002 입니다.

```bash
npm install
npm run dev
```

## 화면

| 주소 | 화면 |
| --- | --- |
| `/` | 홈(히어로 슬라이드 · 철학 · 에센셜 남성/여성 탭 · 시즌 · 신상품 · 매장) |
| `/shop/{men·women}/{new·essential·best}/[라인]/` | 신제품 · 에센셜 · 베스트 목록 |
| `/shop/{men·women}/{all·knitwear·tailoring·outerwear·shirts·tops·trousers·denim·accessories}/[세부]/` | 카테고리 목록(LNB · 세부 줄 · 정렬 · 페이지). 여성은 `dresses`·`skirts`가 더 있습니다 |
| `/shop/upcoming/{men·women}/` | 출시 예정 |
| `/product/{id}/` | 상품 상세(갤러리 · 옵션 · 담기 · 정보 드로어 · 리뷰 · 추천 상품). 색상마다 상품이 따로 있습니다 |
| `/search/?keyword=…` | 검색 결과 |
| `/magazine/{campaign·lookbook·journal}/` | 캠페인 · 룩북 · 저널 목록 |
| `/campaign/{slug}/`, `/lookbook/{slug}/`, `/journal/{slug}/` | 캠페인 · 룩북 · 저널 상세 |
| `/about/`, `/value/`, `/symbol/`, `/contact/`, `/recruit/` | 소개하기 · 가치 · 상징 · 연락망 · 채용 |
| `/online/`, `/offline/`, `/benefit/` | 온라인 · 오프라인 유통망, 회원 전용 혜택 |
| `/shipping/`, `/repairs/`, `/customer-service/`, `/faq/` | 배송 및 교환 · 수선 서비스 · 고객 서비스 · 자주 묻는 질문 |
| `/member/login/`(`?tab=guest`), `/member/join/` | 로그인(회원 · 비회원 배송조회), 회원가입 |
| `/member/find-id/`, `/member/find-password/` | 아이디 · 비밀번호 찾기 |
| `/member/agreement/`, `/member/privacy/` | 이용약관, 개인정보 처리방침 |
| `/cart/`, `/order/` | 쇼핑백, 비회원 주문서 |
| `/myshop/faq/`, `/board/faq/[번호]/`, `/board/review/[번호]/` | 마이쇼핑 FAQ, 이용안내 FAQ 게시판, 리뷰 게시판 |

마이쇼핑의 나머지 메뉴(회원정보 수정·배송지·적립금·쿠폰·주문내역·리뷰 작성)는 레퍼런스처럼 돌아올 주소(`returnUrl`)를 붙여 로그인 화면으로 보냅니다.

## 동작

- **쇼핑백**: 상품 상세에서 사이즈와 수량을 골라 담으면 브라우저 저장소(`slown-store:bag`)에 쌓이고, 머리글 숫자와 쇼핑백 화면에 반영됩니다. 쇼핑백에서는 수량 변경과 선택 삭제가 됩니다. `전체상품 결제`나 `선택상품 결제`를 누르면 로그인 화면이 `비회원 구매` 단추와 함께 열리고, 거기서 비회원 주문서로 넘어갑니다. 결제는 하지 않습니다.
- **목록**: 정렬(인기상품 · 신상품 · 높은 가격 · 낮은 가격)과 페이지가 주소(`?sort=new&page=2`)에 남습니다. 데스크톱은 `필터`를 누르면 정렬 줄이 옆으로 펼쳐지고, 휴대폰은 아래에서 시트가 올라옵니다.
- **상품 상세**: 사이즈를 고르지 않고 담으면 옵션 아래에 안내가 뜹니다. 담으면 `Add to bag` 레이어가 나옵니다. 상세 정보 · 사이즈 안내 · 취급사항 · 필수 표시 · 수선 규정은 데스크톱에서 오른쪽 드로어, 휴대폰에서 아래 시트로 엽니다. 리뷰는 추천 키워드 · 최신순/추천순 · 페이지가 샘플 리뷰를 실제로 거르고, 리뷰 종류 · 별점 · 키 같은 필터 단추는 데모 안내만 띄웁니다. 출시 예정 상품은 구매 대신 `출시 알림 신청`(데모)을 보여 줍니다.
- **회원**: 회원가입은 간편가입 안내로 시작하고, `ID/PW 입력이 필요한 회원가입`을 누르면 가입 양식이 나옵니다. 로그인 화면의 탭으로 비회원 배송조회 양식을 엽니다.
- **양식**: 로그인 · 가입 · 찾기 · 주문서 양식은 칸을 벗어날 때 확인하고, 고치는 즉시 안내를 지웁니다. 올바르게 채우면 "데모 화면이라 실제로 진행되지는 않습니다"만 보여 주고 아무것도 보내지 않습니다. 게시판 댓글도 등록하지 않고 같은 안내만 띄웁니다.
- **매거진**: 캠페인 상세는 썸네일 두 줄이 서로 반대 방향으로 흐르고, 마우스를 올리면 멈춥니다. 룩북 상세는 오른쪽 썸네일 줄에서 룩을 고르면 왼쪽 사진 세 장이 바뀝니다.
- **게시판**: 리뷰 게시판은 제목 · 상품명 검색과 페이지가 되고, 글을 누르면 리뷰 읽기 화면으로 갑니다. 이용안내 FAQ 게시판도 글마다 읽기 화면이 있습니다. 자주 묻는 질문 화면(`/faq/`, `/myshop/faq/`)은 질문을 누르면 답이 펼쳐집니다.
- 오른쪽 아래 `1:1 Talk` 버튼은 데모 안내만 띄웁니다.

## 레퍼런스와 다른 점

- 사진과 영상은 SVG 일러스트로 바꿨습니다. 상품 카드의 사진 세 장은 앞면 · 확대 · 다른 톤 바탕 그림이 대신합니다.
- 상용 서체 대신 Pretendard를 씁니다.
- 레퍼런스는 연락망 · 채용에 예전 머리글을, 이 두 화면과 매거진 목록에 예전 바닥글을 씁니다. 여기서는 모든 화면을 새 머리글 · 바닥글로 맞췄습니다.
- 레퍼런스의 바닥글 아코디언(1440px 미만)은 CSS 때문에 펼쳐도 하위 링크가 보이지 않습니다. 여기서는 펼치면 보입니다.
- 간편 로그인은 실제 서비스 로고 대신 이름 없는 메신저 아이콘으로 두었습니다. 채팅 상담과 리뷰 위젯은 외부 서비스 대신 같은 구성을 샘플 데이터로 직접 그립니다.
- 레퍼런스의 출시 예정 목록은 비어 있었습니다. 화면 틀을 보이려고 샘플 상품 몇 개를 넣었습니다.
- 카페24 주소(`/product/list.html?cate_no=…`, `/product/detail.html?product_no=…`, `/article/review/4/…`)는 `/shop/…`, `/product/…`, `/board/review/…` 같은 정적 경로로 바꿨습니다.
- 동작 줄이기 설정을 켜면 슬라이드 자동 재생, 등장 효과, 흐르는 썸네일을 멈추고 전환 효과를 바로 끝냅니다.

## 배포

`main`에 푸시하면 저장소 루트의 `.github/workflows/deploy.yml`이 이 앱을 `/<repo>/store` 경로로 정적 빌드해 같은 Pages 사이트의 `store/` 아래에 올립니다.

Windows에서 빌드한 `out/`은 직접 올리지 않습니다. Next.js 16.4.2는 Windows에서 링크를 미리 받아 두는 파일(`__next.*.txt`)을 하위 폴더로 나눠 써서, 그대로 올리면 그 요청이 404로 실패합니다. 워크플로는 리눅스에서 빌드하므로 이 문제가 없습니다.
