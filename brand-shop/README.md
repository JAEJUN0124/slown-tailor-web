# SLOWN 브랜드관 — 쇼핑몰 입점 화면 목업 (데모)

가상의 쇼핑몰 `FOLIO SHOP`에 SLOWN이 입점한 브랜드관과, 브랜드관에서 이어지는 몰 화면들입니다. 화면 구조와 수치는 레퍼런스 몰의 브랜드관과 그 하위 화면을 분석해 맞췄고, 몰·계열 편집숍·회사 정보·상품·가격·평점·리뷰·공지·매장·약관은 모두 샘플입니다.

- 스택: Next.js 16(App Router, 정적 export) · React 19 · Tailwind CSS v4 · lucide-react
- 배포 위치: `/<repo>/shop/`

이 폴더(`brand-shop/`)에서 실행합니다. 개발 서버는 http://localhost:3001 입니다.

```bash
npm install
npm run dev
```

## 화면

머리글은 레퍼런스처럼 두 가지입니다. 브랜드 화면은 `src/app/(brand)/`(브랜드 머리글), 몰 공통 화면은 `src/app/(mall)/`(몰 머리글)에 있습니다.

| 주소 | 화면 | 머리글 |
| --- | --- | --- |
| `/` | 브랜드관 메인 | 브랜드 |
| `/list/{men·women·shoes-acc·new·outlet}/[하위]/` | 카테고리·신상품·아울렛 목록 (필터·정렬·페이지) | 브랜드 |
| `/product/{id}/` | 상품 상세 (옵션·장바구니·탭·리뷰·문의) | 브랜드 |
| `/promotions/{id}/` | 기획전 상세 | 브랜드 |
| `/ranking/` | 실시간 판매 랭킹 | 브랜드 |
| `/search/?q=…` | 브랜드관 검색 결과 (`&scope=all`은 통합 검색 문구) | 브랜드 |
| `/promotions/` | 기획전 목록 | 몰 |
| `/cart/` | 장바구니 | 몰 |
| `/login/`, `/login/find/` | 로그인(회원·비회원), 아이디·비밀번호 찾기 | 몰 |
| `/help/`, `/help/faq/[분류]/`, `/help/notice/[번호]/` | 고객센터, FAQ, 공지사항 | 몰 |
| `/help/bulk-order/`, `/help/partnership/`, `/help/vendor/` | 단체주문·제휴문의·입점신청 양식 | 몰 |
| `/stores/` | 매장찾기 | 몰 |
| `/policy/terms/`, `/policy/privacy/`, `/membership/` | 이용약관, 개인정보 처리방침, 멤버십 안내 | 몰 |

찜 목록·마이페이지는 레퍼런스처럼 로그인 화면으로 보냅니다. 몰 카테고리(키즈·뷰티 등)와 다른 브랜드관은 만들지 않고 `#…` 자리표시자로 두었습니다.

## 동작

- **장바구니**: 상품 상세에서 사이즈·배송방법·수량을 골라 담으면 브라우저 저장소(`folio-shop:cart`)에 쌓이고, 머리글 숫자와 장바구니 화면에 반영됩니다. 주문·결제는 하지 않습니다.
- **최근 본 상품**: 상품 상세를 열면 오른쪽 위젯에 쌓입니다(`folio-shop:recent`, 최대 20개).
- **목록**: 가격·사이즈·색상·혜택 필터, 정렬(인기순은 연령대별), 페이지 이동이 샘플 데이터를 실제로 거릅니다. 검색 결과에는 카테고리 필터가 더 있습니다.
- **상품 상세**: 사이즈를 고르지 않고 담으면 안내가 뜹니다. 구매 버튼이 화면 밖으로 나가면 오른쪽에 `구매하기` 탭이 나오고 옵션 패널이 밀려 나옵니다. 리뷰는 종류·옵션 필터와 정렬, 포토리뷰 크게 보기가 됩니다.
- **양식**: 로그인·찾기·문의 양식은 칸을 벗어날 때 확인하고, 고치는 즉시 안내를 지웁니다. 올바르게 채우면 "데모 화면이라 실제로 진행되지는 않습니다"만 보여 주고 아무것도 보내지 않습니다.

## 값 바꾸기

| 파일 | 내용 |
| --- | --- |
| `src/content/shop.ts` | 몰·브랜드 이름, 메뉴, 키비주얼, 메인 코너, 푸터, 랭킹·기획전 문구 |
| `src/content/catalog.ts` | 상품 모델과 색상(색마다 상품 하나), 카테고리 트리, 리뷰·문의 샘플 |
| `src/content/promotions.ts` | 기획전(표지·에디토리얼 블록·상품 탭) |
| `src/content/guide.ts` | 상품 상세의 혜택·안내 문구, 사이즈표, 배송/교환/반품 표 |
| `src/content/help.ts` | 고객센터 메뉴·FAQ·공지·문의 양식 항목 |
| `src/content/policy.ts` · `src/content/stores.ts` | 약관·개인정보 처리방침·멤버십, 매장 목록 |

색은 `src/app/globals.css`의 `--color-shop-*`입니다. 상품 사진 대신 `src/components/ProductArt.tsx`의 SVG 일러스트(18종)를 씁니다.

## 레퍼런스와 다른 점

- 레퍼런스는 PC 전용(최소 폭 1280px)입니다. 1280px 이상은 레퍼런스 수치를 따랐고, 그보다 좁은 화면 배치는 이 목업에서 정했습니다.
- 레퍼런스는 필터·정렬·검색마다 서버에 다시 묻지만, 여기서는 같은 동작을 샘플 데이터에서 바로 처리합니다. 주소는 `/list/…`, `/product/…`처럼 정적 경로로 바꿨습니다.
- 레퍼런스의 브랜드 안 검색은 `/LEMAIRE/undefined`로 이동하는 오류가 있었습니다. 여기서는 검색 결과 화면으로 갑니다.
- 입력 칸의 안내 문구는 칸 안에 있다가 입력하면 위로 올라가는 이름표로 바꿔, 입력 중에도 무엇을 적는 칸인지 보이게 했습니다. 사이즈 탭의 사이즈 가이드는 처음부터 펼쳐 둡니다.
- 간편 로그인은 실제 서비스 로고 대신 이름 없는 아이콘으로 두었습니다. 지도는 그린 약도입니다.
- 동작 줄이기 설정을 켜면 슬라이더가 멈춘 상태로 시작하고 전환 효과를 바로 끝냅니다.
